# 手順内の表・コードブロックが番号付きリストを分断しており Windows コマンド補足も不均一

## 対象

* `management/05.runbooks/review-worker-models/runbook.md`（L43-L50, L69-L74, L80-L85, L92-L95, L101-L102）
* 比較基点：`8ce8f39`

## 指摘内容と根拠

* `## 手順` の番号付きリスト（手順 2・5・6・7）内で、表（L43-L48）およびコードブロック（L69-L72, L80-L83, L92-L95）が 0 桁目（インデントなし）で配置されている。CommonMark / GitHub Flavored Markdown では 0 桁目の表・コードブロックで番号付きリストが終了するため、直後のインデント済み箇条書き（L50, L74, L85）が該当ステップ配下から切り離されて描画される。
* また、Windows 向け `tools\aico.bat` の補足が手順 5（L74）と完了条件（L101）のみにあり、手順 6（L81-L82）・手順 7（L94）・完了条件（L102）には記載がなく不均一である。
* **推奨修正案**：手順 1〜7 を `### 1. ...` 見出し構成へ改める（または表・コードブロックを半角スペース 3 個でインデントする）ことで構造崩れを防ぎ、Windows 環境では `tools/aico.sh` を `tools\aico.bat` に読み替える旨を前提条件または手順冒頭に統一記載する。

## 採否判断（人間選別）

* **判断**：採用（`in-progress`）
* **理由**：Markdown 描画上のリスト分断を根本解消するため手順 1〜7 を `### 1. ...` 見出し構成へ整理し、Windows 環境での `tools\aico.bat` 読み替えルールを手順冒頭へ統一記載する。

## 修正内容

* `management/05.runbooks/review-worker-models/runbook.md` の `## 手順` 配下を `### 1. ...` 〜 `### 7. ...` の H3 見出し構成へ全面整理し、表・コードブロック・箇条書きによる番号付きリスト分断を解消した（作業ツリー上・未コミット）。
* `## 手順` 冒頭へ「※ Windows 環境で実施する場合は、以降の手順および完了条件に記載の `tools/aico.sh` を `tools\aico.bat` に読み替えて実行する。」を統一記載し、各手順・完了条件の個別重複注記を撤去した。
