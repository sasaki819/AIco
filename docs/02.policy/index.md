# AIco ポリシー一覧

## 概要

本ディレクトリでは、AIcoの思想・全体像・判断軸を4レイヤー・8章に整理してまとめる。
AIcoのユーザーが仕様をすべて読み込まなくても思想を理解できる簡潔な解説とし、あわせて仕様・テンプレート設計時の判断軸とする。
具体的な配置・書式・入出力・設定値は仕様書（`docs/03.spec/`）で定め、ポリシーには原則と選定方針のみを記載すること。

## 運用上の約束

ポリシーを参照・改訂する際は、以下の3点を守ること。

* **仕様との線引き**：具体的なファイル書式・モデル名・コマンド引数はポリシーに固定せず、仕様または導入先設定へ分離する。
* **整合性の確認**：仕様やテンプレートを変更する際は、対応するポリシーとの矛盾がないかを確認する。
* **重複の排除**：各方針の詳細は担当章に集約し、他章や本一覧には同じ規則を重複記載しない。
