## 運用上の約束

仕様書を策定・改訂する際は、以下の3点を守ること。

* **ポリシーとの整合**：仕様の変更がポリシーの原則と矛盾しないかを確認し、方針自体が変わる場合はポリシーを先に更新する。
* **実装への具体性**：テンプレート・スキル・スクリプトの実装者が迷わず作成できる粒度まで入出力と制約を明記する。
* **導入先固有値の分離**：モデル名やプロジェクト固有のビルド手順などは仕様へ固定せず、導入先設定へ委ねる。
